# Flux for VS Code

Native Flux language support backed by `flux lsp`.

## Use

1. Install the Flux CLI and this extension.
2. Open a Flux project folder.
3. Edit any `.flux` file for diagnostics, completion, hover, navigation, rename, formatting, quick fixes, signature help, inlay hints, and semantic highlighting.
4. Run **Flux: Run** from the Command Palette to launch the current project.

Set `flux.executablePath` only if `flux` is not on your `PATH`.
